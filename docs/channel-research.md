# 河型与水面联动更新 · 2026-09-08

## 调研依据

1. [USGS：Streamgaging Basics](https://www.usgs.gov/mission-areas/water-resources/science/streamgaging-basics)：流量取决于横断面面积和断面平均速度；应把横断面分成水深不同的条带积分，不能把中心点速度当作整条河的速度。
2. [USGS FEQ：Conservation of Mass](https://cm.water.usgs.gov/proj/feq/feqdoc/chap4html/chap4_4.html)：以 Q = A × V 为断面平均关系。这里用于约束无支流河段的基础输水流场。
3. [US Forest Service 收录研究：Flow structure through pool-riffle sequences](https://research.fs.usda.gov/treesearch/39787)：潭—滩序列具有集中主流、扩散和涡流，不能只做纵向深浅起伏而忽略横向结构。
4. [Byrne 等，2021，Channel Constriction Predicts Pool-Riffle Velocity Reversals Across Landscapes](https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2021GL094378)：宽度、水深及流量共同影响潭滩流速关系，不能概括成“窄的一定白浪，深的一定慢”。本项目没有实现论文的洪水流速反转预测。

以上是机制参考，不是这条虚构河流的实测数据。河段尺寸、涡流强度和白浪阈值是项目内的参数化设计，未经野外标定。

## 本次实现

河型每 62 m 平滑循环，首尾的宽度、中心线和纵深连续。河宽大约 5.2–13 m。河型与底质选择分离，换成沙底不会抹掉深槽和窄口。

| 位置 | 结构 | 水面响应 |
| --- | --- | --- |
| 0 m 附近 | 宽河缓段 | 细纹、清晰反射 |
| 5–12 m | 收窄入口、浅窄急流 | 集流加速、局部驻波、破碎白浪、露石喷溅 |
| 14–20 m | 急流出口、冲刷潭头 | 主流扩散、两侧弱回流 |
| 22–32 m | 宽潭、偏心深槽 | 深色水体、较平滑水面、较慢主流 |
| 36–41 m | 潭尾 tailout | 河床逐渐抬升、水流重新加速 |
| 42–46 m | 卵石浅急滩 | 浅水碎波、石后尾流 |
| 49 m 附近 | 滩后顺流 | 波动衰减，再接宽缓段 |

默认基准深度为 1.5 m，宽潭中心实际深度约 3.3 m；这不是所有位置都等深 1.5 m。界面“上游基准平均流速”控制流量，深度仪和溪流实况显示钓组所在地的实际水深、表层速度。

`channel.js` 提供统一河床、湿岸边界、断面面积、基础流场。基础断面流量数值积分守恒；归一化对数型垂向剖面使近底速度小于表面速度。扩张段增加边界为零的流函数扰动，形成不增加净断面流量的回流。

水底网格、岸线、水面网格都使用同一个断面。GPU 采样 CPU 的基础流场，以局部 Froude 型指标控制波浪与泡沫；深水收窄、低流量时不强制铺满白浪。细波沿累计旅行时间传播，避免 `位置 - 时间 × 局部速度` 导致纹理随时间无限拉碎。漂浮泡沫由 CPU 流场推进，支持汇流和回流。

保留旧钓组动力学、接触处理和评分代码；环境水深和阻力输入按新河型变化。放大了大石碰撞的空间索引覆盖范围，避免大于网格尺寸的石体边缘漏检。原简易版脚本不变。

## 明确边界

- 这是供交互教学使用的参数化准稳态流场，不是 Navier–Stokes / Saint-Venant 水动力求解器，也不是实测河段复刻。
- 平均水面仍用 y=0 基准，水面小尺度起伏是渲染层；没有求解全河段水面落差、回水曲线、洪峰、真实水跃和耗能过程，浮漂浮力仍相对平均水面计算。
- 深槽、冲刷坑和沙洲形态预先参数化，不会随水流实时侵蚀或输沙。
- 钓组主动力学仍以原有纵向 x-y 平面为主；可视粒子和表面泡沫使用横向流场。不宣称完成了三维钓组湍流求解。
- 局部石后阻力仍保留原模型的经验修正，因此“流量守恒”验证针对基础断面场及其回流项，不针对每块石头的附加尾流近似。
- 按自然溪流的潭尾 tailout 实现；坝下尾水 tailwater 不是同一结构，本版没有引入水坝调度场景。
- 回流强弱、Froude 白浪阈值不用于涉水、漂流安全判断。

## 验证方法

`npm run build && npm test`：河型连续性、5.2–13 m 岸线、潭槽与浅滩、不同深度/流量的断面流量、近底剖面、零流量、CPU/GPU 场匹配、钓组核心哈希、资产和 Railway 服务路由。

`node scripts/check-channel.mjs`：CP / Euro 各六个河段跳转、节点有限性、深度仪实时绑定、三档水流、暂停、截图、shader 与浏览器错误。

`node scripts/check-river-repair.mjs`：换深度、DIY、重抛、Euro 拓扑切换、七种底质的碰撞/显示/大石顶高一致性。

`TEST_URL=http://127.0.0.1:4173 node scripts/browser-check.mjs`：与 Railway 相同的生产服务入口，检查四视角、响应式、全部底质、深度变化、简易版往返、404 及资源加载。此次本地通过不代表已部署到线上。
