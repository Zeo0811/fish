# 岸边重建：参考、取舍与验证

2026-09-08。本次只改变岸上地形、材质和植被；河床、流场、线组动力学、评分和简易版不变。

## 真实参考

- [NPS：Riparian Zones—It’s all about the Water](https://www.nps.gov/articles/000/nrca_glca_2021_riparian.htm)：岸带土壤与植被受水分条件影响，悬垂植被也会为水面提供遮阴。借鉴水边至林地的层次，不照搬美国西南部的具体植物名录。
- [NPS：Potomac Gorge Riparian Communities](https://www.nps.gov/pohe/learn/nature/gorge-riparian-comm.htm)：土壤湿度、土质以及砾石/卵石洲使岸带群落不同。对应本项目里不对称、不等宽的裸砾石带和植被斑块。
- [Catskill Streams Buffer Initiative](https://catskillstreams.org/catskill-streams-buffer-initiative/) 的实际溪流照片：前景成丛长草与湿石，后方灌丛和林冠，岸边有自然空隙而不是均匀撒点。
- [All Hands Ecology：Bouverie Preserve](https://www.allhandsecology.org/bouverie-preserve/) 所示 Stuart Creek 实景：草丛根部聚集，河岸存在木质残留物、石块、林下植物和局部悬垂枝叶。参考照片为 David Spangler 拍摄的 Stuart Creek 图片，仅在开发时观察，没有打包或用作游戏贴图。

这是温带林溪的综合视觉参考，并非上述地点的实测地形或植物物种复刻。

## 对应改动

- 用同一湿岸边界向陆地生成湿石/裸砾石、低阶地、草丛和林地；两岸砾石带宽度不同，沿河变化。
- 单一裸土地表改为湿润边缘、砾石、暗色腐殖质和苔藓色斑的 PBR 过渡，叠加实际植被投影。
- 用完整弯曲叶片草丛替代拆开的草叶卡片；根部成束、叶尖散开，包含少量干叶，密度随地表覆盖变化。
- 远处草丛使用同种子的稀疏叶片版本，减少几何开销；保留原始树干精度，枝杈使用较高精度，同时校正远景树图像的根部映射，消除明显悬空。
- 增加灌木群、林下植物和真实三维树木，远景以低成本植被图像补充。原植物组中的独立变体分别校准根部，不再以整组包围盒放置。
- 加入岸上的少量短漂木，避免均匀装饰；不会变成水下隐藏碰撞物。
- 从项目已有 Poly Haven CC0 模型离线生成轻量树木和灌木：三角形减少约 78%–82%，保留原模型和贴图。新增文件和校验写入原素材清单，不依赖 CDN 或线上生成服务。
- 镜头、界面和操作沿用既有版本。新增植被不属于鱼饵碰撞物；此次不改变中鱼逻辑。

## 验证与边界

`tests/riparian.test.mjs` 检查湿岸连接、地表分区、完整草丛、有限顶点和轻量模型。`scripts/check-riparian.mjs` 检查近岸、急流、潭边、俯瞰和全景截图，以及改水深/切等宽河型后的实例根部锚定；根部误差是实例锚点与地面的误差，不代表每片叶子都经过地形碰撞。

植物仍是参考引导的实时模型，远景仍有图像替代，不是照片级离线渲染。低端设备的表现需以实际设备为准；桌面浏览器响应式测试不等同于真机性能测试。
